This package contains the complete, turnkey apparatus for executing **Channel H (Independent Human Validation)** of the ground-truth labels for the paper:

> **"Effect Identity for LLM Agents: Schema-Determined Limits on Duplicate Suppression"**  
> Target Venue: *Artificial Intelligence Journal (AIJ)*

---

## 1. Overview & Ethical Scientific Integrity

In the current paper, ground-truth labels (SAME vs. DIFF) are generated by construction across 1,066 tool-call pairs. To independently audit whether these constructed labels reflect shared operational semantics rather than author idiosyncrasies, an independent annotation study was designed and preregistered (`PROTOCOL.md`).

- **Channel M (Blinded Model Panel):** Completed across three independent models (`groq/compound`, `groq/compound-mini`, `qwen/qwen3.6-27b`) plus an adjudicator (`openai/gpt-oss-safeguard-20b`). This achieved Krippendorff's $\alpha = 0.828$ and 87.9% construction agreement, with 13 of 14 disagreements falling strictly in prose-only residual categories.
- **Channel H (Independent Human Validation):** Specifically instrumented, blinded, and randomized, but **not yet collected from human participants**. In adherence to AIJ standards and academic integrity, model-panel results are NEVER represented as human validation.

This package allows independent research teams or external auditors to collect and analyze human annotations with zero modifications to the core research code.

---

## 2. Package Contents

1. **`PROTOCOL.md`**: Formal study protocol, preregistration specifications, sampling stratification, blinding mechanisms, catch-trial exclusion rules, and decision thresholds.
2. **`INSTRUCTIONS.md`**: Complete, plain-language guidelines provided to human annotators before viewing tasks.
3. **`tasks.jsonl` & `tasks.csv`**: The 154 frozen, blinded, and randomized evaluation items. Contains only item ID, tool name, Call A, and Call B. Absolutely NO ground-truth labels, model predictions, or attack flags are included.
4. **`key.jsonl`**: Sealed key containing stratum metadata, constructed labels, and catch trial flags for automated analysis.
5. **`instrument.html`**: Zero-dependency browser interface (HTML/CSS/JS) presenting one task per screen with forced ternary choices (`SAME`, `DIFF`, `UNSURE`), randomized presentation order, and one-click CSV export.
6. **`analyze_human_study.js`**: Standalone analysis script that ingests human CSV submissions, computes inter-rater reliability metrics, and re-derives mechanism performance under human labels.

## 3. Step-by-Step Execution Guide for Evaluators

### Step 1: Recruit Annotators
Recruit at least 3 independent human annotators with software engineering, systems programming, or API integration experience. Annotators must not be authors of the paper and must not have inspected `corpus/pairs.jsonl`.

### Step 2: Distribute Instructions & Instrument
1. Provide each annotator with `INSTRUCTIONS.md`.
2. Provide each annotator with `instrument.html` (or host it locally). Annotators can open `instrument.html` directly in any modern browser without installing any server or dependencies.
3. Annotators complete all 154 items. The interface forces a ternary choice (`SAME`, `DIFF`, `UNSURE`) and records elapsed time per item.
4. When finished, annotators click **"Export Responses (CSV)"** to download their response file: `responses-<annotator_id>.csv`.

### Step 3: Run Analysis
Place all response CSV files in a directory (e.g., `./submissions/`) and execute:

```bash
node analyze_human_study.js --submissions ./submissions --key key.jsonl
```

The script will automatically:
1. **Audit Catch Trials**: Check items `IT013`, `IT022` (obvious SAME), and `IT108` (obvious DIFF). Any annotator failing any catch trial is dropped in full with an explicit warning.
2. **Compute Inter-Annotator Agreement**:
   - Krippendorff's $\alpha$ (nominal scale, handles missing data)
   - Fleiss' $\kappa$ (ternary scale)
   - Pairwise Cohen's $\kappa$ between all annotator pairs
3. **Compute Construction Agreement**: Overall and per-stratum agreement with 95% Wilson score confidence intervals.
4. **Adjudication**: Identify items requiring adjudication (split votes or ties). If an adjudicator CSV is present (`responses-adjudicator-<id>.csv`), final labels are assigned.
5. **Re-Derivation of Mechanism Safety**: Re-computes wrong-suppression ($WS$) and deduplication ($Dedup$) under human-adjudicated ground truth using the untouched calibration thresholds.

---

## 4. Preregistered Decision Endpoints

- **Primary Endpoint**: If human-adjudicated wrong-suppression ($WS$) on the subset exceeds constructed $WS$ (9.9% [4.9–19.0]) by more than the preregistered margin, the safety claim does not survive independent human relabelling.
- **Secondary Endpoint**: Any stratum with a Wilson 95% upper bound below 80% is declared **contested**.
- **Contested Stratum Prediction**: Based on Channel M findings, category `D2_legit_repeat` and `attack_text` are predicted to be contested due to reliance on free-text prose interpretation.
