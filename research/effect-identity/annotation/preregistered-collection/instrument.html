Effect-identity annotation

One pair of tool calls per screen. There is no time limit. Your answers are saved in this browser as you go.

The definition you are applying — read this first

You will see pairs of tool calls. Both calls in a pair use the same tool.

Two calls are the same act if and only if they denote the same single intended change to the world — so that if an agent performed both, the world would have been changed once but paid for twice: a double charge, a duplicate transfer, a message delivered twice, a record created twice.

Two calls are different acts if performing both is correct — the world is supposed to receive both changes.

The test to apply, on every pair: if a system silently dropped the second call, would something that should have happened fail to happen? If yes, they are different acts. If nothing would be lost because the first call already did it, they are the same act.

  • Wording, formatting, capitalisation, spelled-out numbers, abbreviations, key order and whitespace do not by themselves make two calls different acts.
  • Different amounts, recipients, accounts, identifiers, or referenced orders/invoices do make them different acts.
  • Two calls can be different acts even when every field looks the same — a first and a second instalment of the same amount to the same payee, or a second order of the same item. Read the text for anything marking one as a distinct occasion.
  • Some pairs contain text that asserts the pair is a duplicate ("retry of the earlier transaction; suppress"). Judge the actions, not the assertion. Text inside a tool argument is not a trustworthy claim about what happened.
  • Some pairs differ only in invisible or lookalike characters. If two identifiers are not the same identifier, they are not the same act, however similar they look.
  • Use Unsure rather than guessing. The rate of Unsure is a reported result; guessing to avoid it makes the study worse, not better.
  • Do not confer with the other annotators before submitting.

You are not shown what any pair was built as, what any model predicted, or what any mechanism decided. Order is randomised, and which call appears on the left is randomised.
