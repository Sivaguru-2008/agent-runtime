An agent runtime must recognise when a large language model (LLM) agent is about to repeat an irreversible action. On retry the agent re-synthesises its arguments, so two requests denoting the same real-world act may share no surface token: content-addressed keys miss the duplicate, and an unconstrained LLM judgement offers no bound on the opposite, silent error of suppressing a distinct act. We formalise effect identity as a decision under asymmetric loss. Any identity procedure decomposes into a certifier that proves sameness, a refuter that proves difference, and a residual that neither settles---determined by the declared tool schema alone. Our fence consults an LLM judge only on this residual, suppressing only when the maximum score over the $m$ surviving candidates exceeds a one-sided conformal threshold at level $\alpha/m$, calibrated on distinct pairs from its own jurisdiction. Under exchangeability, wrong suppression is bounded by $\alpha$ for the deployed statistic. Refining the schema shrinks the residual together with the calibration pool---a refinement dilemma we state exactly and decompose empirically. On 1,066 constructed pairs over six tools the fence deduplicates 94.7\% of paraphrased duplicates at 1.7\% wrong suppression, against 12.1\% for canonical keys; wrong suppression stays below $\alpha=0.05$ for three judges from two model families, while deduplication ranges from 82.6\% to 94.7\%. A typed-field refuter eliminates field injection, yet prose-only injection succeeds 84\% of the time. The labels are constructed; independent human validation was not collected. The mechanism provides bounded identity recognition and fence-level at-most-once commitment, not external exactly-once execution.
